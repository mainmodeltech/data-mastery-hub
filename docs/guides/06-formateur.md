# Guide — Profil **Formateur**

> Public : les formateurs, internes ou externes, qui animent des sessions. Prérequis : [bases communes](00-bases-communes.md) (connexion, double authentification).

## 1. Votre rôle

Vous **animez vos sessions** : vous faites l'appel, corrigez les projets finaux, répondez aux questions des apprenants et leur écrivez. Vous ne voyez **que les sessions qui vous sont confiées** (par la pédagogie) — rien d'autre : ni l'argent, ni les candidatures, ni les autres formateurs.

## 2. Ce que vous voyez

Un menu volontairement court : **Mon espace** et **Communauté** (les questions de **vos** sessions).

*Mon espace* → **Mes sessions** : pour chaque session, le nom, la formation, les dates, le nombre d'inscrits, le statut et un bouton **Suivi de session**. Vous voyez aussi la liste des formations de vos sessions, en consultation.

Aucune session ? L'administration (pédagogie) ne vous en a pas encore confié. Prévenez-la.

## 3. Le suivi de session — votre outil principal

*Mon espace → Mes sessions → **Suivi de session**.*

**En haut — les chiffres** : inscrits, progression moyenne, projets à corriger, certificats délivrés, certificats à valider.

**Tableau des apprenants** : pour chacun, la **progression**, l'état du **projet final** et du **certificat**.

### 3.1 Faire l'appel

1. Dans **Lives & présence**, repérer la séance (les séances passées sans appel sont signalées **« Appel à faire »**).
2. **Faire l'appel** → cocher les apprenants **présents** → **Enregistrer** (« Appel enregistré »).
3. Pensez-y **le jour même** : la présence compte pour le **certificat** (un pourcentage de présence aux lives est exigé).
4. En cas d'erreur, rouvrir l'appel et corriger.

### 3.2 Corriger les projets finaux

1. Repérer les apprenants dont le projet est **à corriger** (pastille et colonne *Projet final*).
2. **Corriger** → **télécharger les fichiers rendus** (les liens sont valables **15 minutes** ; en cas d'expiration, rouvrir la fenêtre).
3. Choisir la **décision** : **valider**, ou **demander des modifications** avec un commentaire clair et actionnable.
4. L'apprenant est notifié. Un projet **validé** est une des conditions du certificat.

### 3.3 Répondre aux questions

*Dans la session (« Questions des apprenants ») ou dans le menu **Communauté** → *Questions aux formateurs*.*

- Les questions **sans réponse** sont en tête. **Répondre** : l'apprenant reçoit une notification et un e-mail.
- La zone de réponse est un **éditeur** : gras, liste, lien, et surtout **bloc de code** (coloration automatique, en DAX, SQL, Python…). Utilisez l'onglet **Aperçu** avant d'envoyer. Aucun HTML n'est interprété.
- Répondre de façon **pédagogique** : citer la leçon, expliquer la cause, donner un exemple, proposer un exercice.
- **Objectif conseillé : une réponse sous 24 h ouvrées.** La pastille de la *Communauté* compte les questions sans réponse.

### 3.4 Écrire à la session

*Écrire à la session* : objet + message, envoyé à **tous** les apprenants de la session (rappel de live, consigne, félicitations). L'historique **Messages envoyés** est conservé. Un message = un e-mail : concision, pas de fautes, pas d'information sensible.

### 3.5 Quiz : un apprenant bloqué

Si un apprenant a épuisé ses tentatives, **ouvrir l'apprenant → Quiz → Accorder des tentatives** (nombre + **motif obligatoire**). Il peut recommencer tout de suite. Ce n'est **pas** réservé à la pédagogie : c'est un geste normal du formateur. Chaque attribution est enregistrée à votre nom dans l'audit.

## 4. Ce que vous ne pouvez pas faire (normal)

Modifier le programme (pédagogie / partenaire) · Délivrer un certificat · Ajouter un apprenant à la session (admissions) · Affecter un formateur · Voir les paiements · Voir les sessions des autres formateurs.

Pour toute demande de ce type, passez par la pédagogie.

## 5. À faire régulièrement

| Quand | Action |
|---|---|
| Avant chaque live | Vérifier le lien de connexion (Meet / Zoom) dans le programme — sinon le dire à la pédagogie |
| Juste après chaque live | **Faire l'appel** |
| Chaque jour | Questions sans réponse de vos sessions |
| Chaque semaine | Projets à corriger ; apprenants à faible progression → message à la session |
| En fin de session | Tous les projets corrigés ; liste des apprenants éligibles au certificat communiquée à la pédagogie |

## 6. Parcours à répéter en séance

1. Ouvrir **Mon espace** et entrer dans le **Suivi de session** de test.
2. **Faire l'appel** d'un live, puis le corriger.
3. **Corriger** un projet : télécharger le fichier, demander une modification avec commentaire, puis valider.
4. **Répondre** à une question avec un **bloc de code DAX** ; vérifier l'aperçu.
5. **Écrire à la session** un rappel pour le prochain live.
6. **Accorder une tentative** à un apprenant qui a raté un quiz à 1 tentative.
