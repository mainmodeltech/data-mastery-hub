# Guide — **L'espace apprenant** (pour comprendre et dépanner)

> Public : toute l'équipe. Pour **répondre aux apprenants** et savoir **ce qu'ils voient**, notamment au moment d'un paiement, d'un quiz bloqué ou d'un certificat. Les apprenants n'ont **aucun accès** au back-office.

## 1. Comment un apprenant arrive dans son espace

1. Il dépose une **candidature** sur le site (formulaire, éventuellement avec un **code de parrainage**).
2. Il est **accepté** : il reçoit un e-mail avec son **lien de paiement** (page `Paiement`).
3. Il **paie** (Wave, Orange Money ou virement) puis **déclare** son paiement avec une référence et, s'il le peut, un justificatif.
4. Après **confirmation** par la Finance : son **compte est créé**, il reçoit une **invitation** pour choisir son mot de passe, et son accès s'ouvre.
5. Il se connecte (e-mail + mot de passe, ou lien de connexion reçu par e-mail, ou compte Google) sur `/connexion` → **/espace**.

> « Je n'ai pas reçu l'invitation » : *Journal d'e-mails* (destinataire), puis **Renvoyer l'invitation** dans *Apprenants*. Penser aux courriers indésirables.

## 2. Ce que voit l'apprenant

| Page | Contenu |
|---|---|
| **Mon espace** | « Reprendre » la leçon en cours, **À faire cette semaine**, **prochains lives**, **mes formations** (progression), statistiques (heures suivies, leçons terminées, score moyen aux quiz), certificats |
| **Mes formations** → lecteur de cours | Programme par modules, **vidéo / live / ressource / quiz**, onglets **Ressources, Description, Mes notes** (synchronisées entre appareils), **Poser une question** à l'équipe, **Terminer et suivant** |
| **Modes de lecture** | **Économie de données** (la vidéo ne se charge qu'à la demande), **Audio seul**, **vidéos hors ligne** (si la vidéo est hébergée, pas YouTube/Vimeo) |
| **Évaluations** | Quiz avec chronomètre (reprise possible), correction affichée, **tentatives restantes**, **projet final** (dépôt de fichiers) |
| **Calendrier & lives** | Les séances en direct : **Rejoindre**, **ajouter à son agenda** (.ics) |
| **Ressources** | Les fichiers des formations |
| **Communauté** | Fil d'**entraide** entre apprenants de la même formation (messages, réponses sur un niveau, **code formaté** accepté) |
| **Mes paiements** | Échéances, **reçus PDF**, attestations d'inscription, **payer** une échéance en attente |
| **Certificats** | Certificats **délivrés** : PDF, **lien de vérification**, bouton **LinkedIn** |
| **Mon profil** | Informations personnelles, mot de passe |
| **Hors ligne** | Vidéos téléchargées sur l'appareil |
| Cloche | Notifications (réponse à une question, certificat, paiement…) |

L'espace est pensé pour le **téléphone** (barre d'onglets en bas) et les **connexions lentes**.

## 3. Questions fréquentes et réponse de l'équipe

| L'apprenant dit… | Réponse / action |
|---|---|
| « J'ai payé mais je n'ai pas accès » | Le paiement est-il **déclaré** ? S'il l'est : la **Finance** doit le **confirmer** (pastille *Paiements*). Sinon, lui demander de **déclarer** son paiement depuis son lien. |
| « Mon lien de paiement ne marche plus » | Le lien expire. **Relancer** depuis *Candidatures* (renvoie le lien) ou le **copier** à nouveau. |
| « Mon paiement a été refusé » | Il a reçu un e-mail avec le **motif** ; il peut **redéclarer** avec la bonne référence. |
| « Je suis bloqué au quiz (plus de tentatives) » | Formateur ou pédagogie : **Accorder des tentatives** avec un motif. Il recharge sa page. |
| « Je n'arrive plus à me connecter » | **Mot de passe oublié**, ou **lien de connexion** par e-mail ; vérifier que le compte est **actif** (*Apprenants*). |
| « Où est mon certificat ? » | Il apparaît **après validation** par la pédagogie (voir §4). Vérifier les conditions et l'état dans *Certificats*. |
| « Je ne vois pas la vidéo » | Mode *Économie de données* (cliquer pour charger) ; vérifier que la leçon est **Publiée** ; test avec l'**Aperçu apprenant**. |
| « Ma question n'a pas de réponse » | La retrouver dans *Communauté → Questions aux formateurs* ; la pastille compte les questions sans réponse. |
| « Je veux être remboursé » | **Finance** : *Demander le remboursement* (motif), validé par une autre personne. L'apprenant est informé hors plateforme. |
| « Je veux changer de session » | **Admissions** : annuler / réinscrire selon le cas ; consulter la Direction pour une exception. |

## 4. Le certificat vu par l'apprenant

- Tant que l'équipe n'a pas **validé**, l'apprenant **ne voit rien** et ne reçoit **aucun e-mail** : « Pas encore de certificat » avec un lien « Voir les conditions ».
- Après validation : e-mail + certificat visible + PDF + **page de vérification** publique (`/certificats/…`) que tout employeur peut ouvrir ; un certificat **révoqué** y apparaît comme **non valide**.

## 5. Pour s'exercer

Demander à la Direction les **comptes de test** (jamais les vrais comptes d'apprenants) et parcourir : candidature → paiement → connexion → leçon → quiz → question → certificat.
