# Guide — Profil **Partenaire**

> Public : les organismes partenaires qui dispensent tout ou partie de leurs formations sur la plateforme. Prérequis : [bases communes](00-bases-communes.md) (connexion, double authentification).

## 1. Votre rôle

Vous **éditez le programme de vos formations** : modules, leçons, vidéos, ressources, quiz, projet final. Votre compte est **rattaché à votre organisme** : vous ne voyez **que ses formations** — jamais celles de Model Technologie ni d'un autre partenaire. Vous n'avez accès ni aux paiements, ni aux candidatures, ni aux apprenants.

## 2. Ce que vous voyez

Un menu réduit : **Mon espace** → **Mes formations**. Chaque ligne indique la formation, le domaine, l'organisme, le nombre de sessions et son état (**Publiée** ou **Brouillon**), avec le bouton **Programme**.

Aucune formation ? Votre compte n'est lié à aucune formation : contactez l'administration de Model Technologie.

## 3. Éditer un programme

*Mon espace → Mes formations → **Programme**.* L'éditeur de formation s'ouvre.

### 3.1 Les modules et les leçons

- **Ajouter un module** (titre) ; **monter / descendre** ; **supprimer**.
- **Nouvelle leçon**, quatre types : **Vidéo** (lien **Vimeo** ou **YouTube**, durée), **Ressource**, **Live** (date et heure ; lien Google Meet, Zoom…), **Quiz**.
- **Statut d'une leçon** : *Brouillon* (invisible des apprenants), *Programmé* (visible sans la vidéo), *Publié*. Travaillez en brouillon, publiez quand c'est prêt.
- **Ressources** : nom, type de fichier, adresse du fichier.
- **Réglages du parcours** : modules débloqués dans l'ordre ; accès après la fin de session (12 mois ou à vie).
- **Enregistrer** : si le programme est incomplet, un message indique ce qui manque. Rien n'est perdu tant que vous n'avez pas quitté la page, mais **enregistrez souvent**.

### 3.2 Les quiz

Dans une leçon de type **Quiz** : **nombre de questions tirées au sort**, **seuil de réussite (%)**, **tentatives max** (vide = illimité). Puis **Gérer les questions** (banque de questions) : **énoncé**, **choix** (cocher la bonne réponse), **explication** (affichée dans la correction). Enregistrez d'abord le programme avant de saisir les questions.

> Les réglages des quiz peuvent être corrigés plus tard par la pédagogie ou le formateur : une erreur de tentatives n'est pas définitive.

### 3.3 Le projet final

Onglet **Projet final** : **consigne**, **échéance** (texte libre), **extensions acceptées** (ex. `pdf, zip, pbix`), **taille maximale par fichier (Mo)**.

### 3.4 Aperçu

**Aperçu apprenant** montre la formation comme la voit l'apprenant : vérifiez toujours avant de publier.

## 4. Ce que vous ne pouvez pas faire (normal)

Modifier la fiche de présentation sur le site (prix, description commerciale) · Voir les inscrits ou les paiements · Délivrer des certificats · Affecter un formateur.

Ces actions passent par **Model Technologie** (pédagogie ou finance). La **part de revenu** de votre organisme est fixée contractuellement et enregistrée par la Finance de Model Technologie.

## 5. Bonnes pratiques

- **Droits d'auteur** : n'importer que des contenus dont vous détenez les droits.
- **Vidéos** : privilégier Vimeo (lecture hors ligne possible pour l'apprenant si la vidéo est hébergée) ; vérifier que le lien est **public ou non répertorié**, pas privé.
- **Cohérence** : un module = un objectif ; 3 à 7 leçons ; un quiz de fin de module.
- **Accessibilité** : sous-titres si possible ; ressources en formats courants (PDF, XLSX, PBIX).

## 6. Parcours à répéter en séance

1. Ouvrir **Mes formations** et le **Programme** d'une formation.
2. Ajouter un module avec une vidéo, une ressource et un quiz de 3 questions (seuil 70 %).
3. Passer le module en **Publié**, utiliser l'**Aperçu apprenant**.
4. Définir le **projet final** (extensions `pdf, pbix`, 10 Mo).
5. Constater que les formations des **autres** organismes n'apparaissent pas.
